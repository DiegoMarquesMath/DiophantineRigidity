# Integer-to-complex resultant certification

Goal: for A,W∈ℤ[X] and arbitrary nominal degree parameters D,e,
the map ℤ→ℂ commutes with the Sylvester matrix and its determinant.

This allows a **nonzero complex resultant** to imply the required
**nonzero integral resultant**, with D,e unchanged even if W has
a lower actual degree.

The complex resultant nonvanishing proof is in the separate
zero-kernel/determinant development, PR #10.
The explicit bounded certificate is in PR #5.

Do not mark the research Lemma 4.1 complete here; quantitative
certificates in both charts and p-adic counting remain.
