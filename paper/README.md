# Manuscript policy

Place the author's local revised source here as `ATH_rev.tex` and
`ATH_rev.pdf` when working on statements. These files are ignored by Git.

No version of the unpublished revised manuscript is included in this
repository bootstrap. Source-derived internal audits should be maintained
in `docs/local/`, which is also ignored by Git.

Use `bash scripts/check_source_hashes.sh` to record exact local hashes.
